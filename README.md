# VANGUARD

Tienda de ropa urbana – Proyecto educativo.

## Descripción
VANGUARD es una tienda ficticia desarrollada como proyecto escolar. Su objetivo es simular el funcionamiento de una tienda online, con un diseño moderno y minimalista.

## Tecnologías utilizadas
- HTML5
- CSS3
- JavaScript
- Tailwind CSS

## Funcionalidades
- Página de inicio.
- Catálogo de productos.
- Filtros por categorías.
- Carrito de compras.
- Simulación de pedidos.
- Sección de contacto.
- Diseño adaptable a distintos dispositivos.
